Vessel Reynolds Number Calculator

Equation: Re = (ρ × v × D) / μ

  • ρ: Density of blood (kg/m³, default 1060)
  • v: Velocity (m/s)
  • D: Diameter (m)
  • μ: Dynamic viscosity (Pa·s, default 0.0035)

Womersley Number Calculator

Equation: α = (D / 2) × sqrt(ω / ν)

  • Heart Rate (HR): beats per minute (bpm, default 75)
  • Cardiac Cycle (T): seconds (auto: 60 / HR)
  • Angular Frequency (ω): rad/s (auto: 2π / T)
  • ν: Kinematic viscosity (m²/s, auto: μ / ρ)
  • μ: Dynamic viscosity (Pa·s, default 0.0035)
  • ρ: Density (kg/m³, default 1060)
  • D: Diameter (m, shared with Reynolds)
