## What is AortaCFD?

AortaCFD is an open-source tool for simulating blood flow in patient-specific aortic geometries. Inspired by SimVascular and VMTK, it provides a complete pipeline from medical image segmentation to CFD analysis.

**Problem:** Existing tools are complex and hard to use for clinicians and researchers.

**Solution:** AortaCFD streamlines the workflow with an intuitive interface, robust automation, and clear documentation.
